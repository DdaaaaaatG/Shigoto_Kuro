# overlay 상세 설계 — §9 접근성

> `src/overlay/design.md`에서 분할(40KB 기준, ui-design-strategy §1.2). 절 번호는 주 문서와 같다. 문구·라벨(§8)과 RTM은 주 문서 `src/overlay/design.md`.

## 9. 접근성

- 역할: 오버레이는 방송용 **표시 면**이다. 포커스 가능한 요소가 없고 모든 이미지는 `alt=""`로 보조기술에서 숨긴다(배경 `BackgroundLayer` 포함). SVG 팔은 텍스트가 없다.
- 포커스 순서: 없음(탭 이동 대상 0개). 포커스 링·선택 하이라이트가 보이지 않게 `user-select: none`(전역 규칙, `overlay.module.css`).
- 키보드 조작: 없음. 오버레이의 키 반응은 전역 훅 입력이며 창 포커스와 무관하다. 배율의 키보드 대체 수단은 설정 창 배율 슬라이더(settings R-03 — 보류 해제 → 유효, 결정 D-7 🔒 2026-09-24, CR-029 시점 갱신).
- 마우스 조작: 빈 영역 드래그 = 창 이동(R-12), Ctrl+휠 = 배율(R-04). 위치 잠금 중(R-28, CR-029)에는 core가 창을 클릭 통과로 바꿔 두 조작 모두 오버레이에 닿지 않는다(클릭은 뒤 창으로). 잠금 중 배율 변경·잠금 해제의 대체 수단은 설정 창(배율 슬라이더 settings R-03, 위치 잠금 토글) — 주 문서 §10.9.1.
- 상태 알림: 없음(`aria-live` 영역 없음).
