# settings 상세 설계 — i18n(3개 국어)과 확정 문구 표

- 상위 문서: `src/settings/design.md`(RTM·전체 구조). 이 문서는 design.md §8(확정 문구·라벨 표)의 **이관본**이다(CR-028).
- 요구: R-20(언어 — 설정 창 전체 문구 3개 국어, 라이브러리 없이 사전 객체 + `Messages` 타입, 창 제목·파일 대화상자 제목 포함, 에러 문구는 code로 선택). 문구의 사용처 요구는 표의 「요구」 열.
- 계약: `doc/200_설계/bridge/contract.md` v0.14 §3.3 `Language`, §5.4 `pickPngFile(title?)`·`setSettingsWindowTitle`, §6 에러 코드(정본 `영역.사유`). (CR-035) v0.16 §5.4 `pickFolder(title?)`, §6 `asset.no_default`·`asset.export_dir`, 상수 `DEFAULT_ASSET_SLOTS` — 새 문구는 §4.7.
- 번역 검수: **일본어(ja)·영어(en) 열은 모두 「검수 필요(사용자)」 상태**다. 사용자가 고친 문구는 이 표를 먼저 고치고 `i18n/ja.ts`·`i18n/en.ts`에 전사한다.

## 1. 구조

비유: 번역은 「같은 칸 번호를 가진 세 권의 단어장」이다. 화면은 칸 이름(키)만 알고, 지금 언어의 단어장을 펼쳐 읽는다. 한 권에 칸이 빠지면 TypeScript가 컴파일에서 막는다.

| 파일 | 내용 | 줄 수 목표 |
|---|---|---|
| `src/settings/i18n/types.ts` | `interface Messages`(§2), `type SlotMessageKey`(**20개**, §4.4 — 2026-09-30 doc-sync 소스 대조: `background`·`hair`·`pomo_char`·`pomo_bubble`·`kb_up`·`kb_down`·`idle`·`rest`·`key_*` 7·`mouse_base`·`mouse_left`·`mouse_right`·`pen_up`·`pen_down`. 옛 표기 「24개」는 CR-028 초안 값), `type ErrorCode`(**39개**, §4.6·§4.12 「§4.6 추가분」 — CR-064: 계약 v0.30 §6 중 ui 사전 대상 38개(`reset.forbidden`·`preset.forbidden` 제외) + `unknown`. 이전 27개 = 계약 v0.25 §6 26개 + `unknown`. 옛 표기 「20개」는 v0.14 값), `const ERROR_CODES: readonly ErrorCode[]`(§4.6 순서) | ≤150 |
| `src/settings/i18n/ko.ts` | `export const ko: Messages` — 기존 `src/settings/labels.ts` 전 항목(키 이름 유지, 삭제 키 제외 §5) + 새 문구 | 데이터 상수(400줄 예외 대상이나 ≤400 목표) |
| `src/settings/i18n/ja.ts` | `export const ja: Messages` | 같음 |
| `src/settings/i18n/en.ts` | `export const en: Messages` | 같음 |
| `src/settings/i18n/index.ts` | 순수 함수·상수(§3). React 없음 | ≤100 |
| `src/settings/i18n/MessagesContext.tsx` | `MessagesProvider`·`useMessages`·`useLanguage`(§3) | ≤60 |

- `src/settings/labels.ts`는 **삭제**한다(내용은 `i18n/ko.ts`로 이관). 화면 코드의 `labels.x`는 모두 `t.x`(`const t = useMessages()`)로 바꾼다.
- 새 라이브러리 없음(i18next 등 설치 금지).
- `ko`·`ja`·`en`은 `Messages` 타입 주석(`: Messages`)으로 선언한다 — 키 누락·초과·오타가 `yarn tsc --noEmit`에서 오류가 된다.
- 치환 문구는 `{이름}` 자리표시자를 쓰고 `format()`으로 채운다. 복수형·날짜 형식은 쓰지 않는다.

## 2. `Messages` 타입

```ts
// src/settings/i18n/types.ts
export interface SlotText { title: string; desc: string }
export interface Messages {
  // §4.1 공통 ~ §4.5 어깨축·손 위치 탭의 단순 문자열 키 전부(표의 「키」 열, 점 없는 키) : string
  slots: Record<SlotMessageKey, SlotText>   // §4.4
  errors: Record<ErrorCode, string>          // §4.6 — 객체 키는 문자열 리터럴('asset.too_large' 등)
}
```

- 단순 키 목록은 §4.1·§4.2·§4.3·§4.5 표의 「키」 열과 같다(구현자는 표 순서대로 필드를 적는다).

- `mouseWizard.ts`(순수 모듈)에는 문구를 넣지 않는다(현행 그대로).
- 언어 전환은 **재시작 없이** 다음 렌더에서 전체 문구가 바뀐다: `settings.language`가 `settings://changed`로 바뀌면 `SettingsApp`이 `MessagesProvider`에 새 값을 넘긴다(design.md §5.3).
- 오류 줄·카드 오류 줄·자동 실행 안내는 모두 `errorText` 또는 사전 키로 만든다. 화면 코드에 한국어 문자열 리터럴을 쓰지 않는다(`LANGUAGE_NAMES` 제외).
