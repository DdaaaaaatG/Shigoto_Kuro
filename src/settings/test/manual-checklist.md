## 공통 준비

1. `/dev-start`(또는 빌드된 exe)로 앱을 켠다.
2. 미리보기 확인용 이미지는 「이미지 설정」 탭에서 등록하거나(설정 창 개편 CR-028 이후 등록 UI 있음), 앱 데이터 폴더(`%APPDATA%\com.kuro.keyviewer\`)에 **이미 등록된 상태**(첫 실행 내장 기본 세트 또는 이전 등록분)를 쓴다.
   - 준비 A(기본): 몸통 900×700 + `kb_up` 900×700 + `mouse_base` **손 부분만 그린 작은 그림**(예: 200×150)
   - 준비 B(몸통 없음): `kb_up` 900×700 + `mouse_base` 작은 그림 — 몸통 파일만 뺀다
3. 저장 확인은 `%APPDATA%\com.kuro.keyviewer\settings.json`을 텍스트 편집기로 연다(읽기만).
