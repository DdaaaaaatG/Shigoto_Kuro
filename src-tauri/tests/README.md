# src-tauri/tests — Rust 통합 테스트 자리

- 모듈 단위 테스트는 각 `src/*/mod.rs`(및 하위 파일, 예: `src/assets/slot.rs`)의 `#[cfg(test)]`에 있다 (`cargo test`).
- 이 폴더에는 파일 시스템을 실제로 쓰는 통합 테스트(에셋 가져오기 → manifest → 삭제, 설정 저장/복원)를 둔다.

## 전역 훅은 자동 테스트하지 않는다

`hook/`은 사용자 세션·데스크톱·메시지 루프가 있어야 동작하므로 CI/`cargo test`로 검증할 수 없다. 수동 체크리스트는
**`doc/200_설계/core/hook.md` §8.3**을 따른다(2026-09-24, CR-021로 갱신 — 옛 쾅(키연타)·손바닥 항목은 폐기된
기능을 가리켜 이 문서에서 삭제했다). `yarn tauri dev`에서 확인하고 결과를 `doc/300_검증/`에 남긴다.

요약(전문은 hook.md §8.3):

| # | 확인 | 기대 |
|---|---|---|
| H1~H5 | 훅 설치·누름/뗌·마우스 스로틀·다른 앱 통과·종료 후 해제 | 기존 확정사항 §5 동작 |
| M1~M13 | 특수 키 7종(스페이스·ㅋ/z/Z·?·!·Enter·Backspace·되돌리기) 표시·Shift/Ctrl 조합·IME·Alt·Win 무시 | hook.md §3.1 J1~J11 |
| P-1 | 로그·앱 데이터에 키 정보(분류값·vk)가 남지 않음 | 개인정보 규칙(§1.1) |

키 정보를 로그·콘솔로 찍어 확인하지 않는다(§1.1). 확인은 전용 그림으로만 한다.
