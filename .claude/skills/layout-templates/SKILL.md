# 레이아웃 템플릿

- 화면은 두 개(overlay · settings)뿐이므로 카탈로그는 작다. 여기 없는 구조는 ui-layout-designer가 웹 검색·자체 구성으로 만들고, 재사용 가치가 있으면 `.claude/skills/layout-pool/`에 저장한다(사용자 승인).
- 모든 ASCII는 정렬 불변식을 지킨다: 한글·전각 2칸, ASCII·박스 문자 1칸, 이모지 금지, 박스 안 줄 표시폭 동일.
- 창 크기 전제: settings 기본 900×640(최소 720×520, 크기 조절 가능). overlay는 캔버스 배율에 따라 가변.

---

## 선택 가이드

| 화면 상황 | 패턴 |
|---|---|
| 설정 항목이 3그룹 이상이고 각 그룹이 독립적 | **S1 좌 탭·우 콘텐츠** |
| 이미지·배율·좌표를 바꾸며 결과를 즉시 봐야 함 | **S2 상단 미리보기·하단 폼** |
| 슬롯 여러 개에 이미지를 넣는 것이 주 작업 | **S3 이미지 슬롯 그리드** (S1·S2 안의 한 탭/영역으로 쓰는 것이 보통) |
| 첫 실행에서 필수 6장을 순서대로 넣게 유도 | **S4 마법사 단계형** |
| 입력에 반응하는 투명 오버레이 | **O1 오버레이 캔버스** |

- 설정 화면 기본 추천은 **S1 + (탭 안에 S3·S2 조합)**. 첫 실행 온보딩 요구가 있을 때만 S4.

## S1. 좌 탭 · 우 콘텐츠

```
+------------------------------------------------------------------+
| 제목 바                                                  [닫기]  |
+--------------+---------------------------------------------------+
| 이미지       |  (선택 탭의 콘텐츠)                               |
| 모션         |                                                   |
| 마우스       |                                                   |
| 창           |                                                   |
| 일반         |                                                   |
|              |                                                   |
|              |                                                   |
+--------------+---------------------------------------------------+
| 상태 메시지                                   [초기화]  [저장]   |
+------------------------------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 |
|---|---|---|---|
| 제목 바 | 화면 이름·닫기 | `TitleBar` | — |
| 좌 탭 | 설정 그룹 전환 | `VerticalTabs` | 탭 목록(정적) |
| 우 콘텐츠 | 탭별 폼·슬롯·미리보기 | 탭별 서브 컴포넌트 | `loadSettings` |
| 하단 바 | 저장·초기화·상태 메시지 | `Button`, `StatusText` | `saveSettings` |

- 구현 힌트: 좌 탭 폭 160px 고정, 우 콘텐츠 `overflow: auto`. 탭 전환 시 미저장 변경이 있으면 상태 메시지로 알린다(요구 있을 때만 confirm). 저장 방식(명시 저장 vs 즉시 저장)은 design.md가 확정.

## S2. 상단 미리보기 · 하단 폼

```
+------------------------------------------------------------------+
|                    [ 미리보기 캔버스 450x354 ]                    |
|            (오버레이 렌더 컴포넌트 재사용, 배율 적용)            |
+------------------------------------------------------------------+
| 배율   [----o------] 100%     유휴 시간 [ 5 ] 분                  |
| 쾅     동시 [ 6 ] 키          쾅 유지  [ 300 ] ms                 |
| 어깨 고정점 (x, y)  패드 구역 (x, y, w, h)   [미리보기에서 지정]  |
+------------------------------------------------------------------+
|                                                 [초기화]  [저장]  |
+------------------------------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 |
|---|---|---|---|
| 미리보기 | 현재 설정·이미지로 오버레이와 동일 렌더. 고정점·패드 구역 드래그 지정 | `OverlayCanvas`(공용) + `DragHandle` | 설정·슬롯 이미지 |
| 폼 | 수치 설정 | `Slider`, `NumberInput`, `CoordinateField` | 설정 |
| 하단 바 | 저장·초기화 | `Button` | `saveSettings` |

- 구현 힌트: 미리보기는 실제 입력 대신 「시연」 버튼 또는 미리보기 위 마우스 이동으로 동작을 보여준다(요구에 있을 때만). 미리보기 캔버스는 오버레이 렌더 컴포넌트를 **재사용**한다 — 별도 구현 금지.

## S3. 이미지 슬롯 그리드

```
+------------------------------------------------------------------+
| 상태 레이어 (모두 같은 크기, 최대 900x700, PNG)                   |
| +----------+ +----------+ +----------+ +----------+               |
| |  몸통    | |  대기    | | 쉬는중   | | 키연타   |               |
| |  [img]   | |  [img]   | |  [img]   | |  [img]   |               |
| | 선택 지움| | 선택 지움| | 선택 지움| | 선택 지움|               |
| +----------+ +----------+ +----------+ +----------+               |
| 키보드 파츠                                                       |
| +----------+ +----------+ +----------+ [+ 누름 추가]              |
| |  들림    | | 누름 1   | | 누름 2   |                            |
| +----------+ +----------+ +----------+                            |
| 마우스 파츠 (최대 256x256, 선택)                                  |
| +----------+ +----------+ +----------+                            |
| |  기본    | | 왼클릭   | | 오른클릭 |                            |
| +----------+ +----------+ +----------+                            |
+------------------------------------------------------------------+
| 캔버스 기준: 900x700    상태 메시지                               |
+------------------------------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 |
|---|---|---|---|
| 슬롯 카드 | 썸네일·선택·지움·상태(필수/선택·검증 오류) | `ImageSlot` | `pickImage(slot)` · `clearImage(slot)` |
| 그룹 헤더 | 규격 안내 | `SectionHeader` | 확정사항 §3 |
| 하단 바 | 캔버스 기준 크기·검증 메시지 | `StatusText` | core 검증 결과 |

- 구현 힌트: 슬롯 카드는 한 컴포넌트(`ImageSlot`)로 통일하고 `kind`(상태/키보드/마우스)·`required`·`index` props로 변형. 검증 오류는 슬롯 카드 안에 표시(모달 금지). 「누름 추가」는 요구가 있을 때만.

## S4. 마법사 단계형 (첫 실행 온보딩)

```
+------------------------------------------------------------------+
|  1 몸통  >  2 상태  >  3 키보드  >  4 마우스(선택)  >  5 확인     |
+------------------------------------------------------------------+
|                                                                  |
|            (현재 단계의 슬롯 카드 또는 미리보기)                 |
|                                                                  |
|  안내 문구: 이 단계에서 넣을 이미지와 규격                       |
+------------------------------------------------------------------+
|  [이전]                                        [건너뛰기] [다음] |
+------------------------------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 |
|---|---|---|---|
| 단계 표시 | 진행 위치 | `StepIndicator` | 단계 정의(정적) |
| 단계 본문 | 해당 슬롯 카드(S3 재사용) 또는 최종 미리보기(S2 재사용) | `ImageSlot`, `OverlayCanvas` | 슬롯 상태 |
| 하단 바 | 이동 | `Button` | — |

- 구현 힌트: 필수 슬롯이 비면 「다음」 비활성. 마우스 단계만 「건너뛰기」 허용. 마법사는 S1 설정 화면과 별도 창이 아니라 **같은 창의 첫 실행 모드**로 두는 것을 기본으로 한다.

## O1. 오버레이 캔버스

```
+----------------------------------------------+
|  (투명 — 배경·테두리 없음)                    |
|                                              |
|   z4  마우스 파츠 (좌표 이동 + 팔 곡선)      |
|   z3  키보드 파츠 (들림/누름)                |
|   z2  일반 상태 (대기/쉬는중/키연타)         |
|   z1  몸통                                   |
|                                              |
|   빈 영역 드래그 = 창 이동                   |
|   우클릭 = 컨텍스트 메뉴(요구 있을 때만)     |
|   Ctrl+휠 = 배율                             |
+----------------------------------------------+
```

| 영역 | 역할 | 대표 컴포넌트 | 데이터 |
|---|---|---|---|
| 레이어 스택 | 4종 레이어를 같은 좌표에 겹침 | `OverlayCanvas` → `LayerImage`×n, `MouseHand`, `ArmCurve` | 슬롯 이미지·상태기계 출력 |
| 드래그 핸들 | 빈 영역 드래그로 창 이동 | `DragRegion` | `startDragging()` |
| 컨텍스트 메뉴 | 설정 열기·숨기기·종료 | `ContextMenu` | bridge command |

- 구현 힌트: 컨테이너는 캔버스 기준 크기(예 900×700)를 `transform: scale(배율 × 450/1024)`로 축소한다. 모든 레이어는 `position: absolute; inset: 0`. 마우스 파츠만 `translate`. 팔 곡선은 레이어 스택 위에 놓인 `<canvas>` 한 장. 상태 변화 외에는 리렌더가 없어야 한다(`ui-design-strategy` §6).

---

## 반응형·크기 변화

- settings: 창 폭 < 800이면 S1의 좌 탭을 상단 가로 탭으로 전환. S3 슬롯 그리드는 `auto-fill minmax(140px, 1fr)`.
- overlay: 창 크기는 배율에 따라 core가 조절한다. ui는 컨테이너 크기를 따라가기만 한다.

## 풀 저장 규칙

- 위 카탈로그에 없는 구조를 새로 만들었고 재사용 가치가 있으면 ui-layout-designer가 `.claude/skills/layout-pool/SKILL.md`에 엔트리로 append한다(사용자 승인 후). 엔트리: 이름 / 용도 / ASCII / 영역 표 / 출처 / 최초 등록 화면.
