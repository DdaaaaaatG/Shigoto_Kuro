# originals — 그림 원본 보관 폴더

직접 그린 그림의 **원본**(PNG, 작업 파일)을 두는 곳이다. (사용자 결정 2026-09-30)

- `dist/`에는 원본을 두지 않는다 — `yarn build`가 `dist/`를 통째로 비운다.
- 이 폴더의 그림 파일은 **git에 올라가지 않는다**(`.gitignore`). 저장소가 공개라서다. 이 안내 파일만 커밋된다.
- 앱에 들어가는 내장 기본 그림은 `doc/assets/defaults/`, 개발용 예시 복사본은 `doc/assets/samples/`에 있다.
