# 파츠(이미지) 규격 가이드

- 대상 독자: 스킨(이미지 세트)을 직접 그리는 사람.
- 기준: [`doc/000_프로젝트_확정사항.md`](../000_프로젝트_확정사항.md) §3 이미지 규격, §4 레이어 모델, §5 상태 전이, §6 설정 창 결정(🔒). 두 문서가 어긋나면 확정사항 문서가 맞다.
- 이 문서는 "어떻게 그려야 앱에서 맞게 움직이는가"를 설명한다. 규격 자체를 바꾸려면 확정사항 문서를 먼저 고친다.
- 갱신: 2026-09-28 — CR-053(배포용 기본 세트 3차)까지 반영. 폐기된 옛 규격(쾅 `slam`, 손바닥 모드, 앱이 그리는 팔 곡선, 직사각형 패드 구역 `pad`, 필수 6장)은 §9에 정리했다.

## 1. 한눈에 보기

| 항목 | 값 |
|---|---|
| 파일 형식 | **PNG, 32bit RGBA** (투명 배경 필수). JPG·GIF·WebP 불가 |
| 크기 상한 | 모든 그림 가로 ≤ **900**, 세로 ≤ **700** |
| 파일 용량 | 1장당 ≤ **1 MB** |
| 캔버스 레이어 | 배경·뒷머리·뽀모도·본체(키보드)·대기·쉬는중·특수 키 그림은 **서로 같은 크기**. 첫 번째로 넣은 캔버스 레이어 크기가 캔버스가 된다 |
| 파츠(팔·손) | 팔(`mouse_*`)·손(`pen_*`)은 **크기 자유**(상한만 지킴, CR-036). 필요한 부분만 딱 맞게 그리고, 위치는 설정 창에서 끌어다 놓는다 |
| 권장 캔버스 크기 | **900×700** (비율 9:7. 기본 표시 450×350의 정확히 2배라 축소가 선명하다) |
| 화면 표시 | 기본 450×350 상자에 비율 유지로 축소. 배율 25~200%(200% = 900×700 원본) |
| 필수 | **`kb_up`(키보드 기본 = 캐릭터 본체), `mouse_base`(팔)** 2장. 나머지는 모두 선택 |

모든 캔버스 레이어를 지우면 캔버스 크기도 초기화된다. 봉고캣 원본 스킨(612×354)도 상한 안이라 등록은 되지만 비율(1.73:1)이 달라 450×350 상자 위아래에 여백이 생긴다.

## 2. 레이어 구조 (아래에서 위로 겹침)

```
   ┌────────────────────────────────────────────────┐
   │ 8. 펜 손       pen_up / pen_down_0 (파츠)          │  ← 팔 끝에 붙어 이동, 키 입력 때 교체
   ├────────────────────────────────────────────────┤
   │ 7. 본체 묶음   body → idle/rest → kb_up·kb_down·key_* │  ← 키 입력 때 교체 + 젤리
   ├────────────────────────────────────────────────┤
   │ 6. 팔          mouse_base / left / right (파츠)   │  ← 어깨축 회전 + 늘어나기
   ├────────────────────────────────────────────────┤
   │ 5. 시간 글자   (앱이 그림)                         │  ← 고정
   │ 4. 말풍선      pomo_bubble                         │  ← 고정
   │ 3. 뽀모도 인물 pomo_char                           │  ← 고정
   ├────────────────────────────────────────────────┤
   │ 2. 배경        background                          │  ← 고정, 아무 반응 없음
   ├────────────────────────────────────────────────┤
   │ 1. 뒷머리      hair                                │  ← 본체와 함께 젤리
   └────────────────────────────────────────────────┘
```

- 팔은 **본체 아래**에 깔린다. 팔이 몸 뒤에서 나오는 것처럼 보이므로 본체 그림에 이 팔을 그리지 않는다.
- 뒷머리는 **맨 뒤**다(CR-051). 장발 뒷머리를 본체에 그리면 팔·손을 가리므로 따로 뗀다.
- 젤리 바운스·부르르는 **배경·뽀모도(인물·말풍선·글자)를 뺀 전부**(뒷머리·팔·본체·펜 손)가 한 덩어리로 움직인다.

### 2.1 슬롯 목록

| 그룹 (설정 창) | 슬롯 | 이름 | 종류 | 필수 | 내장 기본 |
|---|---|---|---|---|---|
| 배경 | `background` | 배경 | 캔버스 | | ✅ |
| 배경 | `hair` | 뒷머리 | 캔버스 | | ✅ (「비우기」 가능) |
| 배경 | `pomo_char` | 뽀모도 인물 | 캔버스 | | ✅ (「비우기」 가능) |
| 배경 | `pomo_bubble` | 뽀모도 말풍선 | 캔버스 | | |
| 키보드 | `kb_up` | 키보드 기본(본체) | 캔버스 | ✅ | ✅ |
| 키보드 | `kb_down_0`, `kb_down_1`, … | 타자 입력 1, 2, … | 캔버스 | | (「비우기」 가능) |
| 키보드 | `idle` / `rest` | 대기 / 쉬는중 | 캔버스 | | |
| 키보드 | `key_space` `key_z` `key_question` `key_exclamation` `key_enter` `key_backspace` `key_undo` | 특수 키 7종 | 캔버스 | | |
| 팔 | `mouse_base` | 팔 기본 | 파츠 | ✅ | ✅ |
| 팔 | `mouse_left` / `mouse_right` | 왼클릭 / 오른클릭 | 파츠 | | |
| 손(펜) | `pen_up` | 손 기본 | 파츠 | | ✅ |
| 손(펜) | `pen_down_0` | 펜 입력 1 | 파츠 | | ✅ |

- 내장 기본 그림 7장(`doc/assets/defaults/`)은 앱 데이터가 비어 있을 때 첫 실행에서 채워진다. 카드의 「기본값」은 내장 기본이 있으면 그 그림으로 **복원**, 없으면 **비우기**다.
- `body`(몸통) 슬롯은 앱이 여전히 읽지만(본체 묶음의 맨 아래) **설정 창에 카드가 없다**. 캐릭터 전체는 `kb_up`에 그린다.
- 펜 특수 키(`pen_key_*`)·펜 입력 2장 이상(`pen_down_1+`)은 호환용으로만 남아 있고 앱이 쓰지 않는다(CR-042).
- "키보드+마우스 둘 다" 전용 그림은 **없다**. 레이어가 독립이라 각자 움직인다.

## 3. 슬롯별 그리기 지침

### 3.1 키보드 기본 `kb_up` (필수)
- 캔버스 전체 크기. **캐릭터 본체 전체**(얼굴·몸·책상·키보드)를 그리는 기본 상태다. 따로 몸통을 두지 않는다.
- **마우스 쪽 팔은 그리지 않는다.** 팔은 `mouse_*` 파츠가 본체 아래에서 나온다.
- 펜 손을 쓰는 경우 손도 그리지 않는다(`pen_*`가 본체 위에 올라온다).

### 3.2 타자 입력 `kb_down_0`, `kb_down_1`, …
- 캔버스 전체 크기, `kb_up`과 같은 자리에 **키를 누른 모습**을 그린다(본체 전체를 다시 그려도 된다).
- 여러 장을 넣으면 **누를 때마다 순서대로 순환**한다. 번호는 0부터 빈틈없이.
- 없으면 키를 눌러도 `kb_up` 그대로(젤리 바운스만).
- **펜 손 사용이 켜져 있으면 쓰이지 않는다** — 그때 키보드 레이어는 `kb_up`에 고정되고 손만 바뀐다.
- 이미지 자체를 아래로 그릴 필요는 없다. 앱이 젤리 바운스를 건다.

### 3.3 대기 `idle` / 쉬는중 `rest`
- 캔버스 전체 크기. **본체와 키보드 그림 사이**에 깔리는 표정·효과 레이어. 나머지는 투명.
- `rest`: 설정한 유휴 시간(기본 5분, 60~3600초) 동안 입력이 없을 때. 감은 눈, zzz 등.
- 키보드 그림(`kb_*`)이 **그 위에** 올라오므로, `kb_up`이 불투명하게 덮는 자리에 그리면 보이지 않는다.

### 3.4 특수 키 `key_*` (7종)
- 캔버스 전체 크기. 해당 키를 **누르고 있는 동안** 키보드 그림 대신 보인다. 떼면 `kb_up`.
- 대상: 스페이스 / ㅋ·z·Z / ? / ! / Enter / Backspace / Ctrl+Z(뒤로가기). Ctrl을 누른 채면 Ctrl+Z 외에는 일반 키.
- 없으면 일반 타자 입력 그림(`kb_down`)으로 대체.
- 펜 모드에서도 특수 키 그림은 쓰인다(본체는 `key_*`, 손은 `pen_down_0`).

### 3.5 팔 `mouse_base` / `mouse_left` / `mouse_right`
- **팔(손 포함) 부분만 딱 맞게** 그린 작은 PNG. 투명 여백은 필요 없다. 크기는 제각각이어도 된다.
- 쉬는 자세(회전 0°, 늘어나기 1배)로 그린다. 앱이 이 그림을 **어깨 고정점을 축으로 회전**시키고 **팔 방향으로 0.5~1.6배 늘이거나 줄여** 손끝이 커서 목표점에 닿게 한다.
- 앱은 팔을 따로 그리지 않는다. 어깨 쪽 끝은 본체 뒤로 숨게 그린다.
- 손끝(회전 기준점)은 앱이 자동으로 찾는다 — `mouse_base`의 알파>0 픽셀 중 어깨에서 먼 쪽 25%의 무게중심. 그래서 **어깨 반대쪽 끝이 손**이 되게 그린다. 클릭 그림도 같은 기준점을 쓴다.
- `mouse_left` / `mouse_right`: 클릭하는 동안의 모습. 없으면 `mouse_base`로 대체. 펜 모드에서는 클릭도 키 누름처럼 손이 `pen_down_0`로 바뀌고 젤리가 난다.
- 캔버스 전체 크기 그림을 넣으면 위치 (0, 0)으로 동작한다.

### 3.6 펜 손 `pen_up` / `pen_down_0`
- 팔과 **별개의 작은 손 그림**(펜을 쥔 손). 크기 자유.
- 팔 끝에 붙어 팔을 따라 움직이고 **같은 각도로 기울지만 크기는 늘어나지 않는다**.
- `pen_up` = 평소, `pen_down_0` = 키를 누르거나 클릭하는 동안.
- 설정 「펜 손 사용」(`penMode`)이 켜져 있을 때만 손이 바뀐다. 꺼져 있으면 `pen_up`은 팔 끝에 붙어 따라다니기만 하고, 키 입력은 키보드 그림이 맡는다.

### 3.7 배경 `background` / 뒷머리 `hair`
- 캔버스 전체 크기. 배경은 **아무 반응 없이** 항상 그대로다.
- 뒷머리는 맨 뒤에 깔리고 본체와 함께 젤리로 흔들린다. 단발이면 「비우기」로 뺀다.

### 3.8 뽀모도 `pomo_char` / `pomo_bubble`
- 캔버스 전체 크기. 두 번째 캐릭터와 그 말풍선. 배경처럼 **고정**이고 타이머 on/off와 무관하게 항상 보인다.
- 시간 글자(`00:00:00`)는 앱이 그린다. 말풍선 안에 오도록 설정 창 「타이머」 탭에서 위치·회전·크기·색을 맞춘다.

## 4. 설정 창에서 지정하는 값 (「어깨축·손 위치」 탭)

비유하면 팔은 어깨에 핀으로 꽂힌 종이 인형 팔이다. 핀(어깨축)을 중심으로 돌고, 손끝이 목표점에 닿도록 팔 길이 방향으로만 늘었다 줄었다 한다.

```
 캔버스 (예: 900×700)
 ┌──────────────────────────────────────────────────────┐
 │                (얼굴 — kb_up)                         │
 │                                                      │
 │     ┌─ 파란 상자: 팔 그림 (partPos에 놓임)             │
 │     │   ✋ ← 손끝(자동 기준점)                          │
 │     │    ╲____ 팔 ____●  ← 어깨축 (shoulder)          │
 │     └─ 빨간 상자: 펜 손 (penPos)                       │
 │                                                      │
 │   ◇───────◇                                          │
 │   │ 이동 영역 │ ← 네 점을 클릭해 지정 (area)             │
 │   ◇───────◇                                          │
 └──────────────────────────────────────────────────────┘
```

| 값 | 설명 | 지정 방법 | 기본값 |
|---|---|---|---|
| 어깨축 `shoulder` | 팔이 도는 축 | 「어깨축 설정하기」 → 축 자리 한 번 클릭 → 저장 | (582, 484) |
| 팔 위치 `partPos` | 팔 그림의 왼쪽 위 좌표 | 미리보기에서 팔 그림을 끌어다 놓기 | (411, 464) |
| 손 위치 `penPos` | 쉬는 자세에서 펜 손의 위치 | 미리보기에서 손 그림을 끌어다 놓기 | (372, 476) |
| 이동 영역 `area` | 손끝이 움직이는 자유 사각형(꼭짓점 4개) | 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래 순서로 클릭 | 코드 기본값 |
| 펜 손 사용 `penMode` | 펜 모드 켜기 | 이미지 설정 탭 손 그룹 토글 | 켜짐 |

- 끌기 대상은 누른 자리에 **실제로 그려진(불투명) 그림**으로 정해진다. 둘이 겹치면 위에 있는 손.
- 커서는 **커서가 있는 모니터 기준** 비율로 이동 영역 네 꼭짓점 사이에 옮겨진다. 모니터 오른쪽 아래 구석이면 손끝도 영역의 오른쪽 아래.
- 앱 시작 직후(첫 마우스 이동 전)와 쉬는중에는 팔이 **회전 0°·배율 1**(그린 그대로)로 쉰다.

## 5. 상태 전이 — 스킨 제작자 관점

| 상황 | 상태 레이어 | 키보드 그림 | 팔 | 펜 손(펜 모드) |
|---|---|---|---|---|
| 아무 입력 없음 | `idle` | `kb_up` | 쉬는 자세 | `pen_up` |
| 유휴 시간 무입력 | `rest` | `kb_up` | 쉬는 자세 | `pen_up` |
| 키 누름 | `idle` | `kb_down_N`(순환) + 젤리 → 떼면 `kb_up` | 유지 | 본체 `kb_up` 고정, 손 `pen_down_0` |
| 특수 키 누름 | `idle` | `key_*`(없으면 `kb_down`) + 젤리 | 유지 | 본체 `key_*`(없으면 `kb_up`), 손 `pen_down_0` |
| 키 꾹 누름(자동 반복) | `idle` | 누름 유지 + 부르르 떨림 | 함께 떨림 | 함께 떨림 |
| 마우스 이동 | `idle` | `kb_up` | 커서 따라 회전·늘어나기 | 팔 끝 따라 이동 |
| 마우스 클릭 | `idle` | `kb_up` | `mouse_left`/`mouse_right` | 손 `pen_down_0` + 젤리 |
| 키보드 + 마우스 동시 | 레이어별 규칙 독립 | 누름 | 커서 따라 | — |

- 어떤 키를 눌렀는지는 특수 키 7종 분류만 한다. 입력 내용은 기록하지 않는다.
- Shift·Ctrl·Alt·Win만 꾹 누를 때는 떨지 않는다.

## 6. 겹침 주의

- 팔은 본체 **아래**, 펜 손은 본체 **위**다. 본체(`kb_up`)의 팔이 나올 자리는 비워 두거나, 팔이 몸 뒤로 들어가는 모양으로 그린다.
- 이동 영역이 키보드 그림의 다른 손 위를 지나가면 팔이 그 손 **뒤로** 숨는다. 영역을 두 손이 겹치지 않는 곳에 잡는다.
- `idle`·`rest` 효과는 키보드 그림 **아래**에 깔린다. `kb_up`이 덮는 곳에는 그리지 않는다.
- 캔버스 가장자리에 붙여 그리면 팔이 늘어났을 때나 배율을 키웠을 때 잘릴 수 있다. 여백을 조금 둔다.

## 7. 파일명 예시

앱은 카드를 골라 파일을 선택하는 방식이라 원본 파일명은 자유다. 정리를 위해 슬롯 이름을 권한다. 설정 창 「기본 이미지 다운로드」로 내장 기본 그림을 이 이름으로 받아 트레이싱할 수 있다.

```
my_skin/
├─ background.png    900×700   배경
├─ hair.png          900×700   뒷머리 (선택)
├─ kb_up.png         900×700   본체 전체, 마우스 팔 없음  ← 필수
```

## 8. 제작 체크리스트

- [ ] 모든 파일이 PNG 32bit RGBA(알파 채널 포함)다
- [ ] 캔버스 레이어(배경·뒷머리·뽀모도·kb_*·idle·rest·key_*) 크기가 전부 같다 (권장 900×700)
- [ ] 모든 그림이 900×700·1 MB 이하다
- [ ] 필수 2장(`kb_up`, `mouse_base`)이 있다
- [ ] `kb_up`에 마우스 쪽 팔이 없다 (팔은 `mouse_base`)
- [ ] 팔 그림은 쉬는 자세이고, 어깨 반대쪽 끝이 손이다
- [ ] 펜 손을 쓰면 `kb_up`에 그 손이 없다
- [ ] `kb_down_N` 번호가 0부터 빈틈없이 이어진다
- [ ] 이동 영역이 키보드 그림의 다른 손과 겹치지 않는다
- [ ] 450×350로 축소해도 실루엣이 읽힌다
